# docs.local/

Documentación del proyecto en español, en Markdown siguiendo los estándares de Obsidian
(wikilinks `[[nota]]`, callouts, frontmatter de propiedades) — ver la skill
`.agents/skills/obsidian-markdown/` para la sintaxis exacta.

No es documentación de usuario final ni un README público: es la base de conocimiento
interna del proyecto (decisiones de arquitectura, runbooks, features en curso...). Ábrela
como vault de Obsidian si quieres navegar los wikilinks.

## Convención de subcarpetas sugerida

- `arquitectura/` — decisiones de diseño, ADRs
- `features/` — una nota por feature significativa: qué se hizo y por qué
- `runbooks/` — procedimientos operativos (despliegue, incidentes, tareas recurrentes)

Ajusta esta estructura al proyecto; lo único fijo es que todo vive aquí, en español, y
enlazado con wikilinks cuando tenga sentido.
